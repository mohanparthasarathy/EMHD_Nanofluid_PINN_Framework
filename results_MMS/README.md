# Manufactured-Solution Verification Results

This folder contains `mms_convergence_plot.png`, the manufactured-solution convergence plot used to verify the finite-difference solver.

The verification is regenerated by running the top-level script:

```matlab
verify_FDM_MMS
```

The manufactured-solution test confirms approximately second-order convergence for velocity, concentration, and temperature under mesh refinement. This supports the use of the Crank--Nicolson/Picard finite-difference solver as the synthetic data generator for the inverse-PINN experiments.
