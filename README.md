# EMHD_Nanofluid_PINN_Framework
This repository contains the codebase used in the chapter entitled "Physics-Informed Neural Network Framework for EMHD-Driven Targeted Nanofluid Delivery in the Tumor Microenvironment" in the upcoming edited book "Advances in Nanofluids – Modeling, Simulation, Experimentation, and Applications" to be published in Springer.
